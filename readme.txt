Adds an additional reply link after the last reply of each comment thread.

== Description ==

Adds an additional reply link below the last reply of each top-level comment thread. Supports WordPress comment blocks and standard classic comment lists. The additional link continues the original thread without increasing its nesting depth.

Uses the original WordPress reply handling, author labels, and login requirements. Original reply links remain available without JavaScript.

== Installation ==

1. Install and activate the plugin.
2. Enable nested comments under Settings > Discussion.
